## R2 上下游一页纸（2026-11-08，依据 `EXP-20261108-01`）

1) **在单据链的位置**：`分类树/属性定义（主数据）` → **【分类：给对象打分类 + 按分类检索】** → `对象列表/统计报表`（不参与单据流转，不进入 ERP 下发报文——**未发现分类字段进报文，待验证**）
2) **输入（谁写入）**：① 管理员维护分类树与属性定义（蓝本 `Classify/Edit`、`Classify/Attribute`）；② 业务人员在对象上归类（蓝本 `ClassifyPage` 归类弹窗 + `ClassifyModeAttributePage` 属性录入，属性按 `ISEMPTY` 强校验）；③ 新系统另有图文档分类入口（`doc_class`）。
3) **输出（谁消费）**：① 按分类检索（`ClassifyUse`，含子分类 `DeepSearch`）；② 按分类新建零件（`ClassifyUseMenu.menu:44`）；③ 分类统计四类报表（`REP-H-02`）；④ 对象详情页"分类信息"链接（`PSEItemSeeLinks.link:8-9`）。
4) **共用口径（R2 强制项）**：新系统 `doc_class`（V8）已实现「物化路径树 + 属性（必填/枚举/可继承）+ 按分类检索（含子分类）+ 删除保护」，与本任务能力高度重叠 → **必须在 R3 决定"同表加 `object_type` / 新表 / 抽公共分类内核"**，禁止另写一套（R2 铁律）。文档分类现有数据需评估迁移/共存。
5) **状态机**：分类本身无流转状态；但检索结果列含对象状态 `STARTSTATE`（`CLASSIFYOBJECTVIEW.view:18`）→ 列表要能带对象状态，不能只显示分类字段。
6) **权限**：分类维护与应用是**两个模块级授权**（`ModuleName=Classify` / `ClassifyUse`）+ 动作级（CREATE/EDIT/DELETE/PERMISSION）+ 对象创建权限（`CreatePermission`）+ **部门授权 `PERGROUP`**（检索 SQL 按 `OBJGRPER` 过滤）；新系统映射为「分类维护权限点 + 分类应用权限点 + 沿用对象数据作用域」。
7) **异常与边界**：删除分类需 `ValidateChildLink="CLASSIFYLINK"`（子节点/关联存在则拒绝）；换父级防环（蓝本代码在 DLL 内，**待验证**）；必填属性未填拒绝（`ISEMPTY`）；枚举值必须在字典内。
8) **组织与时间**：分类树本身不按组织隔离，但**部门授权决定可见范围**；检索无期间概念（统计报表才有年/月/周）。
9) **与 ERP/外部接口**：**无直接接口**（分类不进物料报文；物料属性 `FErpClsID` 是独立客制字段，`EXP-20261107-21`）。
10) **不做清单**：四类统计报表（`REP-H-02`）、编码路径自动匹配分类、合并分类保存零件、分类批量导入（待 Q 答复）。

## R3 决策（2026-11-08）

- 处置：**`SUBSTITUTED`**——不复刻蓝本"5 类节点实体 + 通用链接表 `PLMLINK`"元模型，改为"物化路径树 + 独立属性定义 + EAV 值表"，但保持三条语义等价（分类是主数据 / 关系独立且对象不冗余 / 关系指向对象稳定标识）。
- 复用方式：**方案 A**——复用 `doc_class` 既有 `entity_code`（无需新增列），零件归属记 `item_master.class_id`，属性值记 `plm_object.ext_json.classAttrs`。见 `docs/adr/0001-零部件分类复用文档分类表.md`。
- 明确不做（`GAP(T-H-01)`，已登记 `03` B14）：编码路径自动匹配分类、合并分类保存零件、部门授权 `PERGROUP`、枚举按"属性+分类"覆盖、分类批量导入。
