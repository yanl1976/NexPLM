# 复刻工作流 v2（唯一执行口径）

> 背景：此前的做法是"看表结构 + 看数据分布 → 直接写代码"，结果功能像、行为不像。
> 本文把顺序固定下来：**先拿到源实现 → 抽出规则 → 出差异表 → 才允许开发**。
> `docs/12` 保留原理与反模式库，**执行顺序一律以本文为准**。

---

## 0. 一条铁律

**没有可定位的证据（`文件:行号` / 过程名 / 表.字段），不准写业务代码。**

证据只有三种：

| 类型 | 形式 | 来源 |
|---|---|---|
| 源码证据 | `CodeMachine.js:1240-1271`、`CodeResBussiness.cs:88` | 部署目录 + 反编译 |
| SQL 证据 | `PSEBOMLINEEDITCHECKNEW`、`UK_DOC_CLASS_CODE` | 存储过程 / 视图 / 索引 |
| 数据证据 | `PSEITEM.ECODE` 分布、`CODERES.GENERATORPATH` 样本 | 只读查询 |

"我记得蓝本应该是……"不算证据，只能记为**待验证**。

---

## 1. 五个阶段（顺序不可跳）

### P0 取证准备（一次性，每模块复用）

1. 定位部署目录（本项目：`E:\tedri_project\dev\Plm_Code\PLMSOFT`）；
2. 只读复制关键文件到**仓库外**（`PLM_Clone\_plmsoft_probe`），厂商代码不入 Git；
3. 反编译 DLL（工具链见 §4）；
4. 建模块索引：`页面(.page/.js)`、`服务(Service 方法)`、`表`、`过程`。

**产出**：`docs/16-*` 这类资产地图。

### P1 模块盘点（每个业务域一次）

四张清单，缺一不可：

| 清单 | 内容 | 例 |
|---|---|---|
| 页面 | 有哪些页、按钮、字段 | `PSEITEM-CREATE.page` / `ECODE_Value` |
| 服务 | 前端调了哪些服务方法 | `GetPathByCode` / `CheckItemCodeRepeat` |
| 表 | 主表 / 明细 / 快照（`$`）/ 关系 | `PSEITEM` / `PSEITEM$` / `PSEBASEFORM` |
| 过程 | 存储过程、视图、触发器 | `PSEBOMLINEEDITCHECKNEW` |

**产出**：该域的「资产与调用链」小节（`docs/16` 第一、二节即模板）。

### P2 规则卡（每个功能点一张）

字段固定，**一条规则一张卡**：

```
规则编号：CODE-07
功能点：新建物料取号
输入：CodeKindId / ValuePath / GeneratorCount
规则：路径各段取码值对象 ID 前16位拼接；末段流水按种类+路径自增；批量最多5位
证据：CodeMachine.js:1230-1273；CodeValueBussiness.cs:61-140
边界：只算路径(GetCodePath=true)不占号；路径被其他分类占用要报错(CheckRelatedCodePath)
新系统现状：一次一个、路径用文本、无占用校验
差异：D1 批量；D2 路径格式；D3 占用校验
```

**产出**：`docs/rules/<域>.md`（新增目录，按域拆文件，不再往 `06` 堆长文）。

### P3 差异表（开发前必须评审）

| 差异 | 蓝本 | 现状 | 影响 | 处置（改/不改/待业务） |
|---|---|---|---|---|

**没有差异表就不进入 P4**；"待业务"的项必须单独列出，不阻塞其它项。

### P4 开发（一次只动一个规则）

- 一个提交 = 一条规则（或一张卡）；
- 必须先写测试（规则卡的"输入/规则/边界"就是用例）；
- 改动落点写进卡里（类/方法），方便复查。

### P5 验证与收口

| 级别 | 时机 |
|---|---|
| V-片 | 每片（受影响测试类 + 编译；改页面加 `vue-tsc`/`vite build`） |
| V-板块 | 同域多片完成 |
| V-全量 | 迁移 / 公共层 / 板块收口 / 发版 / 全量曾红 |

收口时更新：`06`（一条 EXP，写证据编号）、`03`（台账）、规则卡状态。

## 2. 禁止清单

1. **未读源实现就开发**（本次教训：BOM 判环、编码路径都做成了"看起来对"）。
2. **用"蓝本应该是"填规则**——只能标待验证。
3. **一次提交跨多个模块**。
4. **只写"测试通过"**——必须写跑了哪些类/用例数。
5. **把厂商代码提交进 Git**（只提交我们自己的分析与实现）。
6. **在 `06` 里堆长文代替规则卡**（`06` 只做流水账 + 证据编号）。
